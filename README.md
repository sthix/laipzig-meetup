# lAIpzig Meetup

This is the website of the **lAIpzig Meetup** — an AI Meetup in Leipzig for everyone interested in AI.

Whether you build with agents, tinker with harnesses, train models, or are just curious about where all of this is going, you're welcome here. Topics include:

- AI in general
- Agents
- Harnesses
- LLMs
- Machine Learning
- and everything adjacent

No gatekeeping, no required background — just people who find this stuff interesting.

## Development

Built with [Astro](https://astro.build).

```sh
npm install      # install dependencies
npm run dev      # start the dev server at localhost:4321
npm run build    # build the production site to ./dist
npm run preview  # preview the production build locally
```
